01 · Arquitetura do produto

Feito para quem decide e para quem mantém.

Em vez de relatórios estáticos que envelhecem no dia seguinte, o project-html-docs separa descoberta determinística, autoria estruturada e validação de integridade.

Diagramas 2D determinísticos e Mermaid aprimorado

Blocos solution, flow e schema em Markdown viram SVG inline em grade 2D com zonas empilhadas, cilindros, cartões de decisão compactos, desvio automático de sobreposição de rótulos, realce de conexões no hover e modal com zoom.

Motor em scripts/diagrams.mjs · zero JavaScript externo no navegador

Duas profundidades a partir das mesmas fontes

Gere o Manual Completo (11 capítulos com dicionários pesquisáveis) e o Guia Rápido (4 a 7 capítulos com tempo de leitura estimado), ligados entre si por companionDoc.

mode sections output
"full" 11 documentacao.html
"summary" 4–7 documentacao-resumida.html

Dossiê estático sem executar código

inspect_repo.py mapeia Python, Databricks, PySpark, Delta Lake, Azure Data Factory, Cosmos DB, Event Hubs, FastAPI, SQL lineage e IaC em ondas de leitura com redação automática de segredos.

Manutenção incremental via grafo

Quando o código muda, verify.mjs --impact cruza hashes SHA-256 e dependências transitivas para apontar exatamente quais seções ficaram stale no update-plan.md.

Ergonomia de leitura e temas Vermelho e Azul

Busca instantânea (/ ou Ctrl+K), filtros por audiência (Negócio, Técnico, Operação), tabelas com cabeçalho fixo e filtro local a partir de 8 linhas, além dos temas Vermelho (padrão) e Azul.

02 · Fluxo de trabalho

Quatro etapas do repositório ao HTML auditado.

Cada etapa produz artefatos versionáveis em texto; o HTML final é sempre compilado de forma atômica após passar na auditoria estrutural.

01.

Inspecionar o repositório

Varredura estática com exclusões de .docignore. Gera inventory.json e o roteiro reading-plan.md em 4 ondas.

02.

Escrever manifesto e Markdown

Defina seções, fontes e cartões em document.json; escreva prosa, tabelas, callouts, gráficos e diagramas em content.md.

03.

Compilar o HTML único

build.mjs valida o schema AJV, sanitiza o Markdown, renderiza todos os SVGs inline e audita links, geometria e LaTeX.

04.

Verificar hashes e impacto

verify.mjs confere os SHA-256 gravados no recibo validation.json e calcula quais seções exigem revisão após commits.
